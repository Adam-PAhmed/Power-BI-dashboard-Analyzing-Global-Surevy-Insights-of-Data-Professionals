# 📊 Power BI Dashboard – Global Survey Insights of Data Professionals

This project analyzes global survey responses from 630 data professionals using an interactive Power BI dashboard. The goal is to uncover trends in salary, learning difficulty, programming language usage, and overall job satisfaction across various roles in the data industry.

## 📁 Dataset

- Source: A survey dataset containing responses from 630 individuals working in data-related careers.
- Features include:  
  - Job titles  
  - Countries  
  - Salaries  
  - Favorite programming languages 
  - Perceived difficulty entering the field  
  - Ratings on work-life balance, job satisfaction, and salary satisfaction  

## 🛠 Tools & Technologies

- **Power BI** – for building interactive dashboards and visualizations  
- **Power qeary** – for initial data cleaning and preparation  

## 📊 Dashboard Features

- **Salary Analysis**: Compare average salaries across job roles and countries.  
- **Role Comparison**: Identify trends among different roles (e.g., Data Scientist, Analyst, Engineer).  
- **Programming Languages**: Discover which languages are most commonly used in the field.  
- **Perceived Entry Difficulty**: Analyze how professionals rate the ease of entering data careers.  
- **Job Satisfaction**: Understand how respondents feel about salary, work-life balance, and career growth.  
- **Filters**: Slice data by country, and job title for customized insights.

## 🔍 Key Insights

- 💰 Data Scientists report the highest average salaries ($93K).  
- 🐍 Python is the most widely preffered programming language, with Java being least used.  
- 😐 46% of respondents found it "Easy" or "Very Easy" to enter data roles.  
- ⚖️ Work-life balance and salary satisfaction scores are generally moderate across all job types (except students with salary).
